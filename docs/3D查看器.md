# 3D 轨迹查看器

一个**离线、可复用**的三维轨迹查看器：只读标准 `visualization.json`，
并同步播放该会话的 `derived/annotated.mp4`。不依赖相机、网络或 `stereo` 包。
用于快速检查一条会话的三维形状、逐帧位置和 `X/Y/Z` 数值。

## 运行

```powershell
# 会话目录：自动找 derived/visualization.json + derived/annotated.mp4
python apps\view_3d.py data\sessions\20261020-095331

# 直接给 JSON
python apps\view_3d.py data\sessions\20261020-095331\derived\visualization.json

# 只校验，不开窗口（CI / 远程可用）
python apps\view_3d.py data\sessions\20261020-095331 --check
```

窗口是 **2×2 四宫格**：

```text
┌ 左路追踪视频 ───────┬ 右路追踪视频 ───────┐
│ 球旁 X/Y/Z、原点/轴  │ 球旁 X/Y/Z           │
├ 3D 轨迹 ───────────┼ 右下：待定 ──────────┤
│ 当前球点 + 历史轨迹  │ 预留（误差/速度等）   │
└────────────────────┴────────────────────┘
```

- 视频按 pane 实际尺寸填充，不再保留左右黑边；
- 帧滑块/播放同时驱动左右视频与 3D；
- 右下角暂为“待定”占位，后续再定内容。

`--check` 输出示例：

```text
文件：...\derived\visualization.json
schema=sphere-stereo-visualization version=1
session=20261019-221550 points=293
coordinate_system=rectified_left_camera unit=m
bounds min=[...] max=[...]
```

## 界面与快捷键

| 控件/键 | 作用 |
| --- | --- |
| 左上/右上视频 | `annotated.mp4` 切左右两半，按当前点的 `frame` 号取帧 |
| 左下 3D | 轨迹 + 当前球点 |
| 右下 | 待定占位 |
| 播放 / 暂停 | 3D + 两路视频逐帧动画；空格同效 |
| 帧滑块 | 跳到任意点（两边同步） |
| 速度 | 0.25x / 0.5x / 1x / 2x |
| 重置3D视角 | 把**三维图**的旋转/缩放恢复到初始等比例视角（不影响视频大小）；鼠标拖动后可点它复位 |
| ← / → | 单帧前后 |
| Home | 重置3D视角 |
| 鼠标拖动 | 旋转 3D 视图（matplotlib 原生） |

底部状态栏显示 `frame / t / X / Y / Z / 坐标系`。

视频可以用 `--video <path>` 指定，或 `--no-video` 关闭视频只显示 3D。
找不到视频时会在视频区显示提示，不影响 3D。
`--check` 会打开视频、校验它是否约 2:1 并排、并检查轨迹最大 `frame`
是否落在视频帧数内；`--no-video` 时跳过视频检查。

## 视频叠加内容

`run_stereo_video.py` 生成的 `annotated.mp4` 已包含：

- 球心圆圈 + 历史轨迹线；
- 球旁的 `L/R X=... Y=... Z=... m`（三维坐标）；
- 左图 `O left-cam` 原点和 X/Y/Z 轴（`--origin x,y,z` 可改参照原点）。

> 默认原点是**校正左相机光心的投影**（图像主点附近），不是物理世界原点。
> 如果要在场景里标一个真实参照点，用 `--origin` 传入该点在相机系下的坐标；
> 世界系变换（棋盘 PnP）仍未实现。

## 数据契约

读 `docs/数据标准.md` 的：

- `schema = sphere-stereo-visualization`，`version = 1`；
- `trajectory: [{frame, t, xyz, confident}]`；
- `bounds`、`coordinate_system`、`unit`。

也兼容 `traj3d.json`（`samples` 里 `matched=true` 的点）。

## 限制

- 坐标系是**校正后左相机系**（X 右 / Y 下 / Z 前），不是世界系；
- 只显示已经匹配的三维点，`matched=false` 的帧被跳过；
- 不显示原始视频/检测圈；要看叠加请用 `derived/annotated.mp4`；
- 没有预测轨迹（当前阶段不做预测）。
