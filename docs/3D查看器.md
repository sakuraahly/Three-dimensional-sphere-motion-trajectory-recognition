# 3D 轨迹查看器

一个**离线、可复用**的三维轨迹查看器：只读标准 `visualization.json`，
并同步播放该会话的 `derived/annotated.mp4`。不依赖相机、网络或 `stereo` 包。
用于快速检查一条会话的三维形状、逐帧位置和 `X/Y/Z` 数值。

**打开之后可以换任意会话**（底部「数据源」下拉 + 「打开目录…」），
不用关窗重开；换会话不重建窗口，窗口尺寸、3D 视角、播放速度都保留。
命令行给的 `source` 只是**初始**那一个。

## 运行

```powershell
# 会话目录：自动找 derived/visualization.json + derived/annotated.mp4
python apps\view_3d.py data\stereo\20261020-095331

# 直接给 JSON
python apps\view_3d.py data\stereo\20261020-095331\derived\visualization.json

# 只校验，不开窗口（CI / 远程可用）
python apps\view_3d.py data\stereo\20261020-095331 --check
```

窗口是 **2×2 四宫格**，上下另有控制条与数据源：

```text
┌ 播放 ▾ 重置3D视角  帧 [滑杆] 速度 ▾ ────────────────┐   ← 顶部控制条
├ 左路追踪视频 ───────┬ 右路追踪视频 ───────┤
│ 球旁 X/Y/Z、原点/轴  │ 球旁 X/Y/Z           │
├ 3D 轨迹 ───────────┼ 视角 / 参考平面 ─────┤
│ 当前球点 + 历史轨迹  │ 方向 ▾ 滚转 平面勾选  │
├────────────────────┴────────────────────┤
│ 数据源 [会话下拉 ▾] [打开目录…]  共 N 个会话有结果 │   ← 换会话
├──────────────────────────────────────────┤
│ frame / t / X / Y / Z / 坐标系            │   ← 状态栏
└──────────────────────────────────────────┘
```

- 视频按 pane 实际尺寸填充，不再保留左右黑边；
- 帧滑块/播放同时驱动左右视频与 3D；
- 右下角是**视角 / 参考平面**面板（2026-11-04 起，替代原来的“待定”占位）。
- 「数据源」那一行是 **2026-10-28 加的**：此前源只来自命令行位置参数，
  换一条会话就得关窗重开，而界面侧只能给"最近一个"。

`--check` 输出示例：

```text
文件：...\derived\visualization.json
schema=sphere-stereo-visualization version=1
session=20261019-221550 points=293
coordinate_system=rectified_left_camera unit=m
bounds min=[...] max=[...]
```

## 视角与参考平面（CAD 式，2026-11-04）

### 观察方向

| 选项 | 看的是哪个平面 | 屏幕上 |
| --- | --- | --- |
| 前视（相机看到的） | XY | X 右 / Y 下，与相机画面同向 |
| 后视（从背后） | XY | X 右 / Y 上（从场景回看相机，上下是翻的） |
| 右视 / 左视 | YZ | Z 朝上 |
| 俯视（从头顶） | XZ | X 右，Z 朝上 |
| 仰视（从下方） | XZ | X 左，Z 朝上 |
| 等轴测 | — | 默认视角，看整体形状 |

“前视”用的是 `elev=-90`：matplotlib 的相机位置是
`(cos e·cos a, cos e·sin a, sin e)`，`elev=-90` 把眼睛放在 **-Z**（光心）
朝 +Z 看 —— 与相机拍到的画面同向。写成 `+90` 会从场景背后回看，Y 会翻上去。

**退化轴自动隐藏**：视线正对某根轴时（前后视的 Z、俯仰视的 Y），那根轴在
屏幕上缩成一点，刻度和轴名会全挤在角落糊成一团（实测 89.5° 也救不了）。
所以按 CAD 正视图的惯例把它藏掉，只留有意义的两个轴。

### 任意旋转

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 方位角 + 仰角自由旋转 |
| **Shift + 左键拖动** | 绕**视线轴**滚转（roll）。原生只给两个角，仰角还被夹在 ±90°，少了这个自由度就到不了“从球的正后方斜着看” |
| 滚转滑块 | -180° ~ 180°，与 Shift 拖动双向同步 |
| Home / 重置3D视角 | 回到等轴测，并同时把缩放/平移回初始范围 |

> **2026-11-04 修的老毛病**：以前 `_redraw()` 每帧都调 `_reset_view()`，
> 而它内部会 `view_init(22, -62)` —— 播放时刚转到的角度，下一帧就被打回
> 默认，表现就是“根本转不动”。现在 `_redraw` 只 fit 轴范围，视角由
> `self.view` 持有，**跨帧、跨会话都保留**。

### 三个坐标平面

`XY` / `XZ` / `YZ` 三个勾选框，半透明面 + 网格线，默认全关。

- 平面**过原点**；若某根轴的范围不含 0（相机系里 Z 常是 1~5 m），平面会
  贴到最近的可见边界，面板上注明 `XY 在 Z=0.0349` 这类信息 ——
  否则“勾了没反应”会被当成功能坏了。
- 三个同时开也不会盖住轨迹（alpha 0.06 + 细网格线）。

### 缩放与平移（2026-11-04 二次改版）

| 操作 | 效果 |
| --- | --- |
| 鼠标滚轮 | **定点缩放**：鼠标指向 3D 图的哪个 X/Y 位置，就以那点为锚放大/缩小（指向哪、放大哪） |
| 鼠标中键拖动 | **平移**：前后左右移动视图内容，摄像机不动 |
| 鼠标右键拖动 | 缩放（上下拖动，matplotlib 原生） |
| 左键拖动 | 旋转 |

- **范围是持久状态**：平移/缩放后，播放下一帧**不会弹回**（以前 `_redraw`
  每帧重置范围，表现就是“移动的是坐标轴、一松手又弹回”）；
- 缩放后坐标轴刻度会**自动重新分度**（范围收窄 → 刻度变密）；
- 「重置3D视角」/ Home 会把视角 + 范围一起回初始；
- 滚轮只在指针落在 3D 图上时生效（在视频/面板上滚动不会误缩放）。

### 正交 / 透视

默认**正交投影**（CAD 风格：远近一样大，量长度不会被透视骗）。
取消勾选回到 matplotlib 默认的透视投影，更接近“看照片”的观感。

### 可拖动的四宫格

四个格子（左视频 / 右视频 / 3D / 视角面板）之间是**可拖的分隔条**：按住并拖动
上下两条横条、左右两条竖条即可改变各格大小。视频会按新尺寸重新 cover-crop，
3D 图随画布缩放，面板内容照常显示。初始按 16:9 视频 + 3D 占大头给一个位置，
之后完全由你拖。


## 换会话时的两条硬约束

1. **换失败不许毁掉当前视图**。`open_source()` 先 `load_view()` 再改状态，
   所以坏源（目录里没有 json / schema 不对 / 轨迹为空）只是弹一个提示，
   你正在看的那条不会消失。
2. **切到"没有视频"的会话必须清掉上一段的解码帧**。否则标题、3D 图和状态栏
   都换成了新的，**画面还是上一条**，而且不报任何错 —— 这是最容易误判的一种。

会话列表**按目录名里的时间戳排，不按文件 mtime**：跑一次离线会重写 `derived/`，
把"昨天录、今天补跑"的老会话 mtime 刷成今天，按 mtime 排会把它顶成第一条。

视频可以用 `--video <path>` 指定，或 `--no-video` 关闭视频只显示 3D。
找不到视频时会在视频区显示提示，不影响 3D。
`--check` 会打开视频、校验它是否约 2:1 并排、并检查轨迹最大 `frame`
是否落在视频帧数内；`--no-video` 时跳过视频检查。

## 视频叠加内容

`run_stereo_video.py` 生成的 `annotated.mp4` 已包含：

- 球心圆圈 + 历史轨迹线；
- 球旁的 `L/R X=... Y=... Z=... m`（三维坐标）；
- 左图 `O left-cam` 原点和 X/Y/Z 轴（`--origin x,y,z` 可改参照原点）。

> 默认原点是**校正左相机光心的投影**（图像主点附近），不是物理世界原点。
> 如果要在场景里标一个真实参照点，用 `--origin` 传入该点在相机系下的坐标；
> 世界系变换（棋盘 PnP）仍未实现。

## 数据契约

读 `docs/数据标准.md` 的：

- `schema = sphere-stereo-visualization`，`version = 1`；
- `trajectory: [{frame, t, xyz, confident}]`；
- `bounds`、`coordinate_system`、`unit`。

也兼容 `traj3d.json`（`samples` 里 `matched=true` 的点）。

## 限制

- 坐标系是**校正后左相机系**（X 右 / Y 下 / Z 前），不是世界系；
  “前视”就是按这个轴向摆的（屏幕上 X 右 / Y 下）；
- 只显示已经匹配的三维点，`matched=false` 的帧被跳过；
- 不显示原始视频/检测圈；要看叠加请用 `derived/annotated.mp4`；
- 没有预测轨迹（当前阶段不做预测）。
