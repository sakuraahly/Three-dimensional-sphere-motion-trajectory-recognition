# 3D 轨迹查看器

一个**离线、可复用**的三维轨迹查看器：只读标准 `visualization.json`，
并同步播放该会话的 `derived/annotated.mp4`。不依赖相机、网络，用于检查一条
会话的三维形状、逐帧位置和 X/Y/Z 数值。

> 坐标系约定（默认输出是**相机系**）：**X 向右、Y 向下、Z 向前**，单位米，
> 原点在左相机光心（parallel 是校正后的左相机光心）。看侧视图时横轴是 **Z**，
> 不是 Y —— 这与某些 CAD 里「Z 朝上」的习惯不同，读图前先记住这一条。
> 数据若标了 `coordinate_system=world`（世界系），X/Y/Z 的含义完全不同，
> 见文末「数据契约与限制」；两者的曲线**不能**并排比较。

## 运行

```powershell
# 不带参数 = 自动打开**最新一条**有结果的会话
python apps\view_3d.py

# 指定会话目录 / JSON 文件
python apps\view_3d.py data\stereo\parallel\20261103-093820
python apps\view_3d.py data\stereo\20261020-095331\derived\visualization.json

# 只校验，不开窗口（CI / 远程可用）
python apps\view_3d.py --check
```

`source` 省略时按**会话目录名里的时间戳**挑最新的，不按文件修改时间 ——
补跑一次离线会刷新 `derived/` 的 mtime，按 mtime 排会把老会话顶到第一位。
扫描走 `apps/_stereo_layout.py` 的 `candidate_session_dirs()`，因此
`data/stereo/parallel/` 和 `data/stereo/angled/` 这种按装置分了两层的目录也扫得到。

窗口内换会话用底部「数据源」下拉或「打开目录…」，**不重建窗口**：
视角、播放速度、窗口尺寸都保留；换源失败只弹提示，不会毁掉当前视图。

底部的「视频」下拉可在**窗口内**切换 **标注视频 / 原始视频 / 不看视频**，
同样不重建窗口、不丢当前帧（2026-11-20 补回；旧界面把「原始视频」藏在
数据管理的按钮里）。「原始视频」直接读会话里的 `left/right` 素材：
刚录完还没跑三维时也能看。注意原始帧号与处理帧号只是**近似对齐**，
这个视图用于"看拍到了什么"，不当逐帧测量用。

## 界面布局

```text
┌ 左路追踪视频 ──────────┬ 右路追踪视频 ──────────┐
│ 按当前 frame 号取帧     │ 双目时各占一半          │
├───────────────────────┴────────────────────────┤
│ 3D 轨迹（铺满画布）      │ 视角 / 参考平面（侧栏）  │
│  左上角：坐标极值        │  观察方向、滚转、平面    │
│  左上其下：选中点信息    │  正交投影、等比例坐标    │
│  右下角：X–Z 俯视小图    │  保持立方体比例、分度值  │
├────────────────────────────────────────────────┤
│ 播放 | 重置3D视角 | 最佳视角 | 窗口全屏 |       │
│ -10 -1 [帧滑杆] +1 +10 | 速度 | 平滑            │
├────────────────────────────────────────────────┤
│ 数据源 [会话下拉] [打开目录…] 视频 [标注/原始/不看] │ ? 操作说明 │
├────────────────────────────────────────────────┤
│ frame / t / X / Y / Z / 坐标系 / 视角           │
└────────────────────────────────────────────────┘
```

四格之间的分隔条可拖动。视频按格子实际尺寸等比填充并中心裁剪，不留黑边。
**3D 主图默认铺满整个画布**：3D 的轴标签本来就由 mplot3d 摆在 axes 内部，
不需要像 2D 那样留一圈外边距。需要「不变形」时勾侧栏的
「保持立方体比例（会留白）」，容器会退回正方形，代价是宽屏下左右各留约 17% 空白。

「窗口全屏」只把**窗口**撑到屏幕，不改变坐标轴在画布中的占比 —— 那是布局
开关负责的，两者别混。

## 鼠标与缩放

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 旋转视角 |
| **右键拖动** | **平移**（视野中心跟着走，像人在场景里前后左右移动） |
| 滚轮 | **整幅缩放**：坐标盒、网格、刻度、曲线一起放大 |
| Shift + 滚轮 | 定点放大：只改三轴范围，鼠标指的位置留在屏幕原位 |
| 左键**单击**（位移 < 4 px） | 选中最近的采样点，见下 |
| 点空白处 | 取消选中 |

为什么要分两种缩放：改 `xlim/ylim/zlim` 时盒子大小固定、刻度数量几乎不变，
看起来像「只有曲线在动、背景没动」；`set_box_aspect(zoom=)` 才是整幅放大。
另外范围缩到比数据还小时 mplot3d **不裁剪**，曲线会跑到盒子外面 —— 这也是
为什么右键平移加了边界（视野中心最多走到数据范围外半个跨度就顶住）。

## 观察方向（六视图 + 等轴测）

| 预设 | 屏幕横轴 | 屏幕纵轴 | 退化（自动隐藏） |
| --- | --- | --- | --- |
| 前视（相机看到的） | X 向右 | Y 向下增大 | Z |
| 后视（从背后） | X 向左 | Y 向下增大 | Z |
| **右视** | **Z 向右** | Y 向下增大 | X |
| **左视** | **Z 向左** | Y 向下增大 | X |
| 俯视（从头顶） | X 向右 | Z 向上 | Y |
| 仰视（从下方） | X 向右 | Z 向下 | Y |
| 等轴测 | — | — | 无 |

mplot3d 里 **z 轴默认永远竖直**，光调仰角/方位角换不过来；侧视图必须用
`roll` 把 Z 转平。退化成一点的轴，其刻度和轴名会被自动藏掉（否则全挤在
角落糊成一团）。

「滚转」滑块和 Shift+左键拖动都绕视线轴转 -180°~180°。视角是持久状态，
播放下一帧或切换会话都不会被打回默认。

## 「最佳视角」按钮

两步都按**当前数据**算，不是固定值：

1. **角度** —— 在仰角 15°~60°、方位全周里搜「点云投影面积最大」的方向，
   同时要求视线与任一坐标轴的点积 ≤ 0.75（夹角 ≥ 41°）。没有这条约束时会
   选出「正对 Y 轴」的角度：面积最大，但三根轴的刻度全挤到画布一角，读不出数。
2. **缩放** —— 二分试探 `box_zoom`，让内容（含轴标签）尽量大但不越界。
   用 `get_tightbbox()` 判越界而不是只量点云；后者会把标签挤出画布。

点它会同时把范围回到数据包围盒、清掉选中点。换会话后点一次即可。

## 采样点与坐标读数

轨迹上的每个小圆点就是**一帧真实检测到的球心**（`trajectory` 里的点，和
`samples` 中 `matched=true` 的帧一一对应），不是插值出来的。

- 左键单击某个点 → 画红圈，并在左上角显示 `frame`、时间 `t` 和 X/Y/Z（四位小数）；
- 点空白处 → 取消；
- 勾了「平滑」时线是平滑过的，但采样点仍画在**原始检测位置**，
  正好能看出平滑抹掉了哪些抖动。

左上角常驻的「坐标极值」面板显示三轴的最小 / 最大值和跨度，随会话自动更新。
两个信息框按实测高度上下排列，窗口大小变化时不会重叠。

**分度值 X / Y / Z**（侧栏，单位米/格，留空 = 自动）：填的数字是**每格多少米**。
填好之后视图会按固定 8 格重设该轴显示范围 —— 所以每格变细就是曲线放大、
变粗就是缩小，和示波器的 `V/格` 一个道理。三个轴各管各的，改完按回车
或点别处生效；之后用滚轮 / 右键平移不会被它拽回去。
标签会自动稀疏（屏幕上最多约 9 个数字），网格可以密、字不能糊。

## 播放器

滑杆两侧有 `-10 / -1 / +1 / +10` 四个步进按钮：±1 精确定位，±10 快速扫一段
（几百帧的会话里拖滑杆很难对准某一帧）。按步进会先暂停播放，否则下一次刷新
立刻把帧号推走。播放 / 暂停、速度 0.25x~2x、平滑开关都在同一条控制条上。

视频按当前三维点的 `frame` 号取同一帧，左右切开分别显示。若提示

> 视频只有 19 帧，当前要点第 63 帧 —— annotated.mp4 不完整（生成中断或被覆盖）

那是**视频文件本身不完整**（原始 `left.mkv` / `right.mkv`（或 `left.avi` / `right.avi`）通常还在，重跑离线
流程可补），不是解码器坏了。帧号在范围内却读不出来才报真正的解码失败。

## 参考平面与投影

`XY` / `XZ` / `YZ` 三个勾选框画半透明面 + 细网格线，默认全关。平面过原点；
若某轴范围不含 0（相机系里 Z 常在 1~5 m），会贴到最近的可见边界，并在面板上
注明 `XY 在 Z=0.0349`，否则「勾了没反应」会被当成功能坏了。

默认**正交投影**（CAD 风格，远近一样大，量长度不会被透视骗）；取消勾选回到透视。
「等比例坐标（真实几何）」勾上后按真实米数设三轴比例 —— 形状是真的，但跨度
小的那根轴会真的短；不勾时三轴各自拉满，便于看轨迹形状。
**不勾时短轴会被放大**（跨度 0.48 m 对 0.065 m 时约 7 倍），所以三轴跨度比超过
3 倍时，侧栏提示标签会写明「非等比例：Y 轴被放大约 N 倍，形状会失真」——
看形状之前先看一眼这句话，做几何判断请勾「等比例坐标」。

## 数据契约与限制

读 `docs/数据标准.md`：`schema = sphere-stereo-visualization`、`version = 1`、
`trajectory: [{frame, t, xyz, confident}]`、`bounds`、`coordinate_system`、`unit`。
也兼容 `traj3d.json`（`samples` 里 `matched=true` 的点）。

- 坐标可能是相机系（平行：校正后左相机系；大角度：左相机系）或**世界系**，
  以 `visualization.json` 的 `coordinate_system` 为准。世界系由
  `config/world_frame.json`（`set_world_frame.py` 生成）提供，目前只支持
  **angled**（parallel 的校正系会拒绝变换并说明原因）。数据是世界系时，
  轴标签自动变成 `World X / Y / Z`，不再写死相机系的 `X right / Y down / Z forward`：
  - `World X` = 棋盘**列向**；
  - `World Y` = 棋盘**行向**（`ground_axis=z` 时朝画面下方，`-z` 时反向）；
  - `World Z` = **棋盘法向** —— 标签里的 "ground normal" 指的就是这一条法向线。
    板平放时它与竖直方向共线，但**朝上还是朝下由世界系文件里的 `ground_axis` 决定**
    （`config/world_frame.json` 那个键，`visualization.json` 的 `notes` 里写明了用的是哪个文件）：
    `z`（默认）朝**地下**，`-z` 朝**天空**（此时 Y 也反向，右手系的代价）。
    看数值前先确认这一项，否则"球的高度"会整体反号。完整定义见
    `docs/数据标准.md` §6「世界系」；
- 只显示已匹配的三维点，`matched=false` 的帧被跳过；
- 视频叠加内容（球心圈、历史轨迹、X/Y/Z 文字、原点轴）由
  `apps/run_stereo_video.py` 预先画进 `annotated.mp4`，查看器不重新渲染；
- 没有预测轨迹（当前阶段不做预测）。

## 验证

```powershell
python -m py_compile apps\view_3d.py
python apps\view_3d.py --check
python apps\run_tests.py fast -j auto
```

3D 查看器相关的判据在 `tests/selftest_launcher_params.py` 的 8d / 8e 节
（六视图的轴方向、缩放、拾取、面板不重叠、帮助入口），以及
`tests/selftest_gui_budget.py`、`tests/selftest_viz_scale.py`。

界面观感需人眼确认：Tk 窗口在远程/无桌面会话里抓不到截图。控件几何可以用
`get_window_extent` 断言，但「好不好看」只能现场看。
