# 3D 轨迹查看器

一个**离线、可复用**的三维轨迹查看器：只读标准 `visualization.json`，
不依赖相机、网络或 `stereo` 包。用于快速检查一条会话的三维形状、逐帧位置和
`X/Y/Z` 数值。

## 运行

```powershell
# 会话目录：自动找 derived/visualization.json，找不到再用 traj3d.json
python apps\view_3d.py data\sessions\20261019-221550

# 直接给 JSON
python apps\view_3d.py data\sessions\20261019-221550\derived\visualization.json

# 只校验，不开窗口（CI / 远程可用）
python apps\view_3d.py data\sessions\20261019-221550 --check
```

`--check` 输出示例：

```text
文件：...\derived\visualization.json
schema=sphere-stereo-visualization version=1
session=20261019-221550 points=293
coordinate_system=rectified_left_camera unit=m
bounds min=[...] max=[...]
```

## 界面与快捷键

| 控件/键 | 作用 |
| --- | --- |
| 播放 / 暂停 | 逐帧动画；空格同效 |
| 帧滑块 | 跳到任意点 |
| 速度 | 0.25x / 0.5x / 1x / 2x |
| 重置视角 | 回到等比例视角 |
| ← / → | 单帧前后 |
| Home | 重置视角 |
| 鼠标拖动 | 旋转 3D 视图（matplotlib 原生） |

底部状态栏显示 `frame / t / X / Y / Z / 坐标系`。

## 数据契约

读 `docs/数据标准.md` 的：

- `schema = sphere-stereo-visualization`，`version = 1`；
- `trajectory: [{frame, t, xyz, confident}]`；
- `bounds`、`coordinate_system`、`unit`。

也兼容 `traj3d.json`（`samples` 里 `matched=true` 的点）。

## 限制

- 坐标系是**校正后左相机系**（X 右 / Y 前 / Z 上），不是世界系；
- 只显示已经匹配的三维点，`matched=false` 的帧被跳过；
- 不显示原始视频/检测圈；要看叠加请用 `derived/annotated.mp4`；
- 没有预测轨迹（当前阶段不做预测）。
