# 摄像头设备管理（索引固定 / 端口识别 / 启动自动选择）

## Context（为什么做）

排查「左边窗口是外接、右边却是笔记本内置」这个问题时暴露出三个真实缺陷：

1. **索引会漂移**：`cv2.VideoCapture(index)` 的编号由系统枚举顺序决定。今天实测到 —— 同一台机器上，
   换过一次 USB 口之后，**编号 2 从「第二台外接」直接消失、系统的摄像头列表从 3 台变成 2 台**；
   同型号相机在注册表里留下一堆 `CM_PROB_PHANTOM` 幽灵记录，连设备名都被带偏。
   启动器把 `--left 0 --right 2` 写死，索引一变就悄悄用错设备，标定白做。
2. **认不出"哪台是外接、插在哪个口"**：`apps/tools/list_cameras.py` 只能按注册表顺序**猜**设备名，
   而实测证明这个顺序和 OpenCV 的实际索引**不一致**。
3. **没有"自动挑一台能用的"能力**：`run_realtime.py --camera` 写死默认 0；
   双目标定必须手填两个编号。

目标：把"相机身份"从"索引"里解耦出来 —— 配置里记**稳定身份（USB 端口 / PnP InstanceId）**，
每次启动解析成当前索引；解析不上就**列出来让你自己选**，绝不替你猜。

## 关键约束与本方案的诚实边界

- **硬约束**：`tests/selftest_pair_source.py` 断言 `from_args` 在 `--left/--right` 全空时**必须抛 `RuntimeError`**。
  因此「自动选择」必须是**显式开关**，不能做成静默兜底。
- **无法绕过的事实**：OpenCV 只能按索引开设备，**读不到"索引 N 对应哪个物理设备"**。
  索引↔身份的对应只能靠"枚举顺序"去推 —— 这是**启发式，不是真值**。
  本方案不试图消灭它，而是用「目视确认(identify) → 写进配置 → 启动时打印解析结果 → check 检测漂移」把它**暴露出来并纠正**。
- **可靠的部分**：某索引能不能开、是否全黑、真实分辨率/帧率（`CameraSource` 实测）；
  Windows PnP 的 `Present` / `InstanceId` / `LocationInformation`（PowerShell 能跑时）；
  配置读写与纯函数解析（可被单测完全覆盖）。
- **启发式部分**：枚举位次↔cv2 索引；"外接 vs 内置"按设备名判断；"端口→索引"。
- 按你的选择：**只做 Windows**，非 Windows 平台退化为纯索引模式（`list_devices()` 返回空，功能不报错但无身份识别）。

## 你已拍板的三个决定

| 决定 | 结论 |
|---|---|
| 配置与实物对不上时 | **列出来让你自己选**（交互式选择；无法交互时打印清单并要求显式指定，不静默兜底） |
| 单目 `--camera` 默认 | 改成**启动时自动挑最优**（显式传 `--camera 0` 仍按索引走） |
| 跨平台 | **只做 Windows**，其它平台退化为纯索引 |

## 一、新建 `sphere_tracker/camera_registry.py`（库，纯 stdlib）

层级与 `sources.py` 同层（`track/predict/sources/viz`），**惰性** import `.sources`，不制造反向依赖。

```python
_CFG = Path(__file__).resolve().parents[1] / "config" / "cameras.json"   # 同 _MODE_CACHE 约定

@dataclass(frozen=True)
class DeviceEntry:
    order: int          # 枚举位次；== 我们所"相信"的 cv2 索引（启发式）
    name: str           # FriendlyName，如 "aoni webcam A25"
    identity: str       # Win: PnP InstanceId（同一 USB 口上稳定）
    port: str = ""      # Win: "Port_#0001.Hub_#0003"（取自 LocationInformation）
    present: bool = True  # 幽灵记录过滤（PowerShell 可用时可靠；不可用则恒 True=未知）
    source: str = "index"  # registry / powershell / index

@dataclass
class RoleSpec:
    identity: str = ""; port: str = ""; name: str = ""
    index: int | None = None
    verified: bool = False   # 是否经 identify 目视确认

@dataclass
class Registry:
    v: int = 1
    roles: dict[str, RoleSpec] = field(default_factory=dict)
    settings: dict = field(default_factory=dict)

@dataclass(frozen=True)
class ProbeResult:
    index: int; ok: bool; width: int = 0; height: int = 0; fps: float = 0.0
    std: float = 0.0; error: str = ""; entry: DeviceEntry | None = None
```

**函数（全部"永不抛异常"，除标注处）**

## 二、新建 `apps/tools/cameras.py`（工具）

复用 `list_cameras.py` 的 `ROOT` 注入写法；`argparse` 子命令：

| 子命令 | 作用 |
|---|---|
| `list [--probe] [--json] [--max-index N]` | 列设备：`索引 / 设备名 / 端口 / Present / 来源`；`--probe` 才真的开相机（无相机环境也能跑 `list`） |
| `identify [--indices 0,1,2]` | **逐个索引开实时预览**，窗口标题 + 画面左上角大字叠加 `#索引 \| 设备名 \| 端口`；按提示输入角色名（left/right/main）→ 写入 `config/cameras.json`（`verified=true`）。拿不到身份时记索引并明确告警"重插后可能漂移" |
| `pin <role> <0|port:..|id:..|name:..>` | 非交互写角色；只能拿到索引时打印"建议改用 identify 目视确认" |
| `check` | 逐角色比对"期望身份 vs 当前解析结果"：一致 ✅ / 漂移（按身份纠正）⚠ / 对上但**设备名或端口不符** → `[危险]` 且退出码 2 |

## 三、接入调用链（`PairSource` / `CameraPairReader` **一行不改**）

### 3.1 `stereo/pair_source.py::from_args`（唯一的接缝）

在传参前把 `--left/--right` **归一化成 int**，其余语义原样：

```python
left_raw, right_raw = getattr(args, "left", None), getattr(args, "right", None)
auto = bool(getattr(args, "auto_cameras", False)) or left_raw == "auto" or right_raw == "auto"

if auto or (left_raw is not None and right_raw is not None):
    if auto:
        picks = select_cameras(need=2, ...)
        if len(picks) < 2:
            raise RuntimeError("自动选择失败：没找到两台可用的相机。请跑 "
                               "python apps/tools/cameras.py list，或用 --left 0 --right 2 手动指定。")
        left_i, right_i = picks[0].index, picks[1].index
        print(f"[自动选择] 左 #{left_i}｜右 #{right_i}")
    else:
        left_i, right_i = resolve_camera_arg(left_raw), resolve_camera_arg(right_raw)
    return PairSource(camera=(left_i, right_i), width=args.width, height=args.height,
                      fps=args.fps, backup_camera=getattr(args, "backup_camera", None),
                      backend=resolve_backend(getattr(args, "backend", None)))
# ↓ 以下两分支与现状完全一致（video / directory），最后仍抛 RuntimeError
```

**回归安全性**：`ns()`（left/right 均 None）三支都不进 → 仍抛 `RuntimeError` ✅；
`resolve_camera_arg(int)` 原样返回 int → `CameraPairReader` 收到的仍是 int ✅。

### 3.2 三个 app 的 argparse

`apps/calibrate_stereo.py`、`apps/verify_stereo.py`、`apps/tools/check_stereo_setup.py` 统一：

- `--left` / `--right`：去掉 `type=int`，默认 `None`，帮助文案写「索引(0) / 角色名(left) / auto」；
- 新增 `--auto-cameras`（`store_true`）。
- 其余（`--backend`、`--backup-camera`、`--width/--height/--fps`）不动。

### 3.3 `apps/run_realtime.py`

`--camera` 的 `default` 由 `0` 改为 `None`：为 `None` 时调 `select_cameras(need=1)`（优先外接、避开

## 五、错误处理矩阵

| 场景 | 行为 |
|---|---|
| 设备不存在 / 角色无匹配 | 打印设备清单；可交互则让你选，否则抛 `RuntimeError` + 指路 `cameras.py` |
| **索引被别的设备占用**（1 从外接变内置） | `check` 打 `[危险]` 且退出码 2；解析时若 `verified=True` 但 name/port 不符 → 同上走"让你选" |
| 端口/设备被别的程序占用（QQ/会议/Hello） | `probe_index` 记 error，换下一位候选；全失败沿用 `CameraSource` 既有四条排查文案 |
| PowerShell 被拒 / 超时 / 无 powershell | `_run_powershell` 返回 None → 跳过 Present 过滤，`source="registry"`，输出提示"身份不完整，建议 identify 目视确认"，**不崩** |
| 无任何可用相机 | `select_cameras` 返回空 → `from_args` 抛"没找到可用相机" |
| 双路配不上（后端/集线器） | 沿用 `CameraPairReader` 现有报错（已含"插到不同 USB 口"建议） |
| `config/cameras.json` 损坏/不存在 | `load_registry` 返回空，不抛；提示"未固定，建议先 identify" |
| 非 Windows / 拿不到身份 | 退化为纯索引，全程带 warning，不报错 |

## 六、回归测试 `tests/selftest_camera_registry.py`

按项目既有风格（自攒 `checks: list[tuple[str,bool]]`、逐条 `[通过/不达标]`、`return 0 if ok else 1`、不用 pytest）。
**全部外部 I/O 注入假数据，全程不开相机** → 无相机机器上稳定通过。覆盖：

1. `parse_windows_instance` 解析（含/不含 `&MI_00`）；
2. `windows_devices`：合并注册表+PnP、幽灵(`present=False`)被剔除、`order` 连续；
3. 降级：`pnp_reader` 抛异常 → 不崩、`source=="registry"`、`present` 全 True；
4. **解析优先级**：identity 命中 / identity 缺失走 port / 再走 name / 全缺失走 index（带 warning）；
5. **冲突用例**：port 与 name 指向不同设备 → port 优先；
6. **危险用例**：pin 了 `index=0`+identity A，现在 devices[0] 变成内置 → 断言**绝不静默返回 0 的内置**；
7. `resolve_camera_arg`：`0`/`"0"`/`"left"`/`"port:..."`/未知角色抛错；
8. 配置往返 + 文件写坏时 `load_registry` 返回空不抛；
9. `select_cameras` 排序：跳过内置/IR/全黑/打不开，无可用时返回空 list 不抛；
10. **`from_args` 兼容性**：`left="0", right="2"` 走通；**复刻 `ns()` 情形断言仍抛 `RuntimeError`**（守护硬约束）。

```
python tests\selftest_camera_registry.py            # 无相机即可通过
python tests\selftest_camera_registry.py --probe    # 有相机时额外验证真机
```
