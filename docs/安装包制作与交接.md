> **这份文档给"接手做安装包的人"**。看完应当能：独立重建 setup.exe、在真机上验一遍、遇到报错能自己定位。
> 面向使用者的说明在 `docs/用户手册.md` §2.2.1；发布流程与分支规则在 `docs/Git分支与发布规范.md` §6。

## 2. 最快上手：三条命令

前置（只需一次）：

```bat
:: 1) Python 3.10+（打包机自己的，用来跑 build_runtime / make_clean_bundle）
python --version

:: 2) Inno Setup 6（编译器）
winget install --id JRSoftware.InnoSetup -e

:: 3) （仅首次或改了 Go 代码时才需要）重建 launcher.exe
cd native\launcher && build.bat && cd ..\..
```

出包：

```bat
installer\build_installer.bat
:: → outputs\releases\SphereMotion-0.3.0-setup.exe
```

不想装 Inno 也能先自检：

```bat
python installer\verify_payload.py        :: 源码 payload 完整性
python installer\build_runtime.py --check  :: 内嵌 Python 能否 import 全部依赖
```

> `build_installer.bat` 里带 `pause`，适合双击；要在无人值守脚本里跑，
> 直接调 `ISCC.exe installer\sphere_motion.iss`（见 §5 第 4 步）。

## 3. 安装包里到底装了什么

```
{app} = %LOCALAPPDATA%\SphereMotion   （默认；免管理员、不写 Program Files）
├── launcher.exe              无黑框启动器（Go 编译，1.9 MB）
├── run.bat / install.bat / uninstall.bat
├── apps/ sphere_tracker/ calib/ stereo/ assets/ docs/ models/ …
│                             源码与资源，来自 make_clean_bundle.py 的白名单
├── config/
│   └── python_env.txt        ★ 解释器指针，安装器在最后一步写入
└── runtime/
    └── python/               ★ 内嵌 Python 3.14.10（仅当用户选"用自带的"才复制）
        ├── python.exe / pythonw.exe
        ├── DLLs/ Lib/ tcl/
        └── Lib/site-packages/     cv2, numpy, scipy, matplotlib, PIL, yaml …
```

装完约 **406 MB / 6176 文件**（含内嵌运行时时）。

**为什么内嵌运行时是"构建产物"而不是入库文件**：它 391 MB、由固定版本的官方
发行版 + pip 安装得到；入库会让仓库爆炸，也会让"同一份源码对应哪份运行时"变成
不可复现的二进制。所以：源码在仓库，运行时由 `installer/build_runtime.py` 现场构建。

## 4. 向导里的解释器选择（这是核心，改之前先读懂）

### 4.1 用户看到的

安装到「Python runtime」页时两个单选项：

- **Use the bundled Python 3.14（默认）** → 复制 `runtime\`，开箱即用；
- **Use a Python already installed** → 出现文件选择页，选 `python.exe`；
  安装器会真跑 `import cv2, numpy` 校验，**不合格不放行**；选它就不复制运行时。

### 4.2 代码在哪

全在 `installer/sphere_motion.iss` 的 `[Code]` 段，共 5 个入口：

| 符号 | 作用 |
| --- | --- |
| `InitializeWizard` | 创建 `ChoicePage`（`CreateInputOptionPage` 单选）+ `PathPage`（`CreateInputFilePage` 浏览） |
| `ShouldSkipPage` | 选"自带"时跳过 `PathPage` |
| `NextButtonClick` | 选外部解释器时校验：文件存在 + `Exec(py, '-c "import cv2, numpy"')` 返回 0 |
| `WantBundledPython` | 给 `[Files]` 的 `Check:` 用——选"自带"才复制 `runtime\*` |
| `CurStepChanged(ssPostInstall)` | 写 `config/python_env.txt` |

### 4.3 指针协议（三方同读，改格式要三处一起改）

`config/python_env.txt` 是纯文本 `key=value`，**故意不用 JSON**——安装那一刻可能
连 Python 都没配好，不能靠 Python 解析。

```
# sphere-python-env v1 - generated by installer; do not edit
python=runtime/python/python.exe     ← 仓库内写相对路径；仓库外写绝对路径
kind=bundled                          ← bundled | adopted | venv | …
created=by-installer
python_version=3.14.10
verified=cv2,numpy,scipy,tkinter
```

三个读者：

| 读者 | 位置 | 行为 |
| --- | --- | --- |
| Go launcher | `native/launcher/main.go` 的 `pointerPython()` | 相对路径按 `root` 还原，**优先于一切候选** |
| bat | `run.bat` 的 `for /f` 读 `python=` | 直接当 `PY` 用 |
| Python | `apps/setup_env.py` 的 `parse_pointer()` | 跳过 `#` 注释，相对值按 `root` 还原 |

**换解释器的两种方式**：改这个文件的 `python=` 一行；或重跑安装向导。
`kind` 只是给人和日志看的标签，程序判据只看 `python=`。

### 4.4 已知边界

- 不校验外部解释器的**版本下限**（只验能不能 import）。3.10+ 才支持本项目的语法，
  但真装了 3.9 会报语法错——属"用户自己选错"，安装器不拦。
- 静默安装（`/VERYSILENT`）默认走"自带"，不会弹选择页。

## 5. 构建链路（4 步，出错就停在哪步）

`installer\build_installer.bat` 依次做：

| 步 | 动作 | 产物/校验 | 失败常见原因 |
| --- | --- | --- | --- |
| 1 | `apps/tools/make_clean_bundle.py` | `outputs/release_payload_src.zip`（233 文件） | 白名单与实际文件不一致（`--check` 会指出） |
| 2 | `installer/build_runtime.py` | `outputs/release_stage/runtime/python/`（391 MB） | 网络断、sha256 不符、pip 装不上 |
| 3 | 解压源码到 staging + 放 `launcher.exe` | `outputs/release_stage/` | 根目录没有 `launcher.exe`（先 `cd native\launcher && build.bat`） |
| 4 | `ISCC.exe installer\sphere_motion.iss` | `outputs/releases/*-setup.exe` | `.iss` 语法/路径/语言文件（见 §7） |

第 2 步的细节（想改 Python 版本或依赖时看这里）：

- 版本、URL、**sha256**、依赖清单全部集中在 `installer/build_runtime.py` 顶部；
- 下载缓存 `outputs/runtime_cache/`，命中就不重下；
- 装完会删 `__pycache__` 和包自带 tests（约省 82 MB），然后跑一次 import 自检。

**第 3 步为什么要"把 runtime 挪出去再挪回来"**：脚本要 `rmdir /s /q
outputs\release_stage` 才能干净解压源码包，但 runtime 是几百 MB 的产物，
被一起删掉要重装几分钟。所以先 `move` 到 `outputs/runtime_cache/staged`，再挪回。

## 6. 常见修改点（照做即可）

| 想改什么 | 改哪 | 注意 |
| --- | --- | --- |
| 版本号 | `installer/sphere_motion.iss` 的 `#define AppVer` | 同时改 `build_installer.bat` 里的两处版本提示文案 |
| 默认安装目录 | `.iss` 的 `DefaultDirName` | 保持 `{localappdata}` 或 `{autopf}`；写死盘符会让别人装不上 |
| 内嵌 Python 版本 | `build_runtime.py` 的 `PY_VERSION` / `RELEASE_TAG` / `SHA256` | 三者必须同一次 GitHub release；sha256 从 release API 的 `digest` 取 |
| 依赖清单 | `requirements.txt` | 改完删缓存重跑 `build_runtime.py --force` |
| 向导文案 | `.iss` 的 `InitializeWizard` 三个字符串 + `[Tasks]` 的 Description | 中文要确认语言文件支持，否则用英文 |
| 加中文向导 | 从 jrsoftware.org 下 `islang.exe`，把 `ChineseSimplified.isl` 放进 Inno 的 `Languages\`，再把 `[Languages]` 换成 | winget 版只带 29 种欧洲语言，**不含中文** |
| 桌面快捷方式默认勾选 | `.iss` `[Tasks]` 的 `Flags:` | 现在是 `desktopicon` 不勾（`unchecked`）、`startmenu` 勾（`checkedonce`）；**别往桌面默认塞东西** |
| 安装器要不要装依赖 | 现在是"内嵌好、直接可用"，不再需要首次启动下载 | 若改回"首启装依赖"，要同步改 `launcher.exe` 的引导文案 |

## 7. 已知坑（全是实测踩过的，别再踩）

| 现象 | 根因 | 解法 |
| --- | --- | --- |
| 双击 setup.exe 报 `Setup was unable to create the directory "...\Temp\is-XXXX.tmp"` / `Error 5: 拒绝访问` | **360安全卫士 / 火绒（联想版）等 HIPS 拦截"未签名 exe 在 Temp 释放可执行文件"**；Temp 的 ACL 本身正常 | ① 把 setup.exe 加信任区或临时关防护；② 先把 `TMP`/`TEMP` 指到别的盘再运行（见 §8.2，已验证可过）。根治要代码签名证书 |
| 第一次运行弹 SmartScreen"Windows 已保护你的电脑" | 无代码签名 | 预期行为。正式对外发布前买证书签名；不要为消警告去改判据 |
| 装完桌面莫名其妙多了快捷方式 | `[Tasks]` 没设默认状态时 Inno **默认全勾** | `desktopicon` 必须 `Flags: unchecked`；`startmenu` 用 `Flags: checkedonce` |
| 编译报 `Unknown identifier 'FormatDateTime'` / `'DateToStr'` | Inno 的 Pascal 脚本子集**没有**这两个函数 | 别在 `.iss` 里格式化时间；`created=` 写固定值即可（只是元数据） |
| 编译报 `CreateInputFilePage` 参数错 | 它只收 **4 个**参数（AfterID + 3 个文案） | 别多传空串 |
| 编译报图标/`runtime` 路径找不到 | ISCC 以 `.iss` 所在目录（`installer\`）为相对路径基准 | `#define StageDir "..\outputs\release_stage"` 回退一层；**不要**用 `/S` 想改基准——那是 SignTool 选项 |
| 编译报语言文件不存在 | winget 国际版没有 `ChineseSimplified.isl` | 先用 `compiler:Default.isl`；要中文按 §6 下载语言包 |
| `build_installer.bat` 找不到 ISCC | winget 装到了 `%LOCALAPPDATA%\Programs\Inno Setup 6`，不是 Program Files | 脚本已按三个位置依次找；换机器时确认路径 |
| 装完启动报"找不到 Python" | `config/python_env.txt` 没写成功，或 `kind=bundled` 但 `runtime\` 被跳过 | 看安装日志的 `CurStepChanged` 段；确认 `[Files]` 的 `Check: WantBundledPython` 与选择一致 |
| 卸载后目录里还剩空文件夹 | Inno 只删自己登记的文件，空目录偶尔留下 | 无害；要彻底干净就在 `[UninstallDelete]` 里补 `filesanddirs` |

## 8. 验证清单（接手后照着走一遍）

### 8.1 静态自检（30 秒，不需要装任何东西）

```bat
python apps\tools\check_standards.py    :: 文档/引用/计数/待办 四类
python installer\verify_payload.py      :: 源码 payload 233 文件 + launcher.exe 合法 + 图标可达
python installer\build_runtime.py --check  :: 内嵌 Python 能 import cv2/numpy/scipy/tkinter
python tests\selftest_installer_runtime.py  :: .iss 与指针协议的静态判据
```

四条都要「全部通过」才算可发包。

### 8.2 真机安装（10 分钟）

> ⚠️ **不要装到 C 盘临时目录**。若机器上装了 360/火绒，按下面把临时目录指到别的盘。

```powershell
# 以普通权限的 PowerShell 执行
$base = "D:\SphereMotionTest"
New-Item -ItemType Directory -Force "$base\tmp","$base\app" | Out-Null
Copy-Item "outputs\releases\SphereMotion-0.3.0-setup.exe" "$base\setup.exe" -Force
$env:TMP = "$base\tmp"; $env:TEMP = "$base\tmp"      # 绕开 C 盘 Temp 被拦
Start-Process "$base\setup.exe" `
  -ArgumentList '/VERYSILENT','/SUPPRESSMSGBOXES','/NORESTART',"/DIR=$base\app","/LOG=$base\install.log" `
  -Wait
```

装完逐项核对（这 8 项都过才算成功）：

| # | 检查 | 期望 |
| --- | --- | --- |
| 1 | 安装退出码 | `0`；日志末尾 `Installation process succeeded` |
| 2 | 目录规模 | 约 406 MB / 6176 文件 |
| 3 | 关键入口 | `launcher.exe` / `run.bat` / `apps\gui_main.py` / `runtime\python\python.exe` 都在 |
| 4 | 指针内容 | `python=runtime/python/python.exe`、`kind=bundled`、`python_version=3.14.10` |
| 5 | 内嵌环境 | `runtime\python\python.exe -c "import cv2,numpy,scipy,tkinter"` 无报错 |
| 6 | launcher 认路 | `launcher.exe --dry-run` 输出的 `pointer` / `python` / `guiPython` 全指向安装目录内 `runtime\python\*`，且 `tried 1 candidates` |
| 7 | 桌面行为 | **没有**桌面快捷方式（`desktopicon` 默认不勾）；开始菜单有 3 项（主程序 / 安装环境 / 卸载） |
| 8 | 卸载 | 跑 `{app}\unins000.exe /VERYSILENT`，退出码 0，桌面/开始菜单/`HKCU\...\Uninstall` 全清 |

### 8.3 交互式安装（看向导长相）

同上，但不加 `/VERYSILENT`，人工点过「Python runtime」页：
选"自带"→ 直接下一步；选"外部"→ 浏览选一个**没装 cv2 的** python.exe，
应当被拦住并提示。这一步验的是 `NextButtonClick` 的校验真的生效。

## 9. 还没做的事（按优先级）

| 项 | 为什么重要 | 怎么做 |
| --- | --- | --- |
| **代码签名证书** | 现在 360/火绒会拦、SmartScreen 会警告；对外分发这是硬门槛 | 买 OV/EV 证书 → Inno 的 `SignTool` 配置 → 重编译。**没有证书时不要声称"可直接分发"** |

| **CI 里自动打包** | 现在只能在本机手动出包 | 加一个 `workflow_dispatch` job：装 Inno → `build_installer.bat` → 传 artifact。注意 CI 上要能下载 22 MB 运行时 |
| **发布到 GitHub Release** | 产物目前只在本机 | 按 `docs/Git分支与发布规范.md` §6.3，**需负责人批准**；dev 快照 tag 不必合 main |
| **GUI 内切换解释器** | 现在换解释器要手改 `config/python_env.txt` 或重跑向导 | 在设置页加一项，写同一个指针文件（不要让 GUI 自己发明第二套格式） |

| 真机标定闭环 | 与安装包无关，但比安装包更影响"能不能用" | 见 `docs/真机标定操作清单.md` 与 `docs/人工参与清单.md` |
