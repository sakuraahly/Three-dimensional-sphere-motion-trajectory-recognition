## 一、先拍板三件事（不定这三件，后面都做不了）

### 1. 你要的"90°"是哪种装置？

| 方案 | 需要什么 | 能看到什么 | 代价 |
| ---- | -------- | ---------- | ---- |
| **A. 保持现在（近平行）** | 不用改硬件 | 现在的 1.4° 装置，能做球的三维重建 | 软件里的 `angled` 用不上；"90°"只是理论 |
| **B. 真做对称 90°** | 两相机中心距 **B≈2×工作距离 D**；D=0.3 m ⇒ **B≈600 mm** | 真正的正交双目，遮挡更少 | 要换支架/加长横梁；两路共同可见区变小 |
| **C. 折中（推荐先试）** | B 能拉到多少算多少（比如 300–400 mm） | 夹角自然落在 40–60°，仍用 `angled` 路径 | 成本低；先把"大角度"这条路跑通，再决定要不要上 90° |

**关键事实**：现在的 B=124 mm，做对称 90° 只能对应 **D≈62 mm**（球几乎贴到镜头），不现实。
这不是软件限制，是几何限制。

**请你回答**：选 A / B / C，以及**你实际希望的工作距离 D 是多少**（例如 0.3 m / 0.5 m / 1 m）。

**请你回答**：逐类说"删 / 归档 / 保留"，我按你的决定批量执行（会先出清单让你确认，不直接删）。

**请你回答**：你的球心定位要达到多少毫米？如果要求 <2 mm，就必须重标 + 加长基线，软件层面已经没有余量了。

## 二、物理准备（只有你能做，做完我再验证）

### 通用（A/B/C 都要）

- [ ] 两台相机**刚性固定**在同一根导轨/型材上，之后不要再碰。碰一次就要重标。
- [ ] **对焦/曝光/白平衡全部锁死**（手动模式）。自动曝光一抖，颜色线索就废。
- [ ] 左路清晰度历史上有问题（§15.7 记过"左路虚"）。**用眼睛看**：把标定板放中间，两路画面都要能数清格子。
- [ ] 光照均匀，标定板不过曝也不发黑（过曝会让角点检测直接失败）。
- [ ] 记下标定板到两相机中点的距离 D，以及两相机中心距 B（卷尺量，±2 mm 就够——
      **因为 B 只用于参考提示，判定一律以标定结果为准**）。

### 只有 B / C 需要

- [ ] 两相机光轴夹角按目标摆；**摆完先算一遍**：`估算夹角 ≈ 2·atan(B / (2D))`
      （B=600, D=300 → 90°；B=124, D=300 → 23.4°；B=124, D=62 → 90°）。
- [ ] **确认两路能看到同一块区域**：在共同可见区放标定板，两路画面里都要出现**完整**棋盘。
      90° 装置最容易死在这一点上——两个窄扇形只有中间一楔形重叠。

## 三、标定（GUI 点法，约 15 分钟）

1. 打开 `启动程序.bat` → 第 1 步 → **「前置检查」**：确认两路都出图、分辨率一致、没有报红。
2. 点 **「装置档案」** → 只填 **名称 + 模式**（90° 选 `angled`）→ 保存并设为当前。
   **基线/工作距离可以留空**——它们只用于参考提示，不参与判定。
3. 第 1 步 → **「标定（90° 装置，跳过 FOV）」**（若选 A 方案，用普通「开始标定」）。
4. 按提示摆板：8×5 内角点、方格 25 mm，收 **40 对**；每次停稳再动。
   - 看到「棋盘还在移动」→ 手停 2 秒再拍，这是**物理问题**不是软件问题。
   - 看到「清晰度不足」→ 对焦/距离问题，不是参数问题。
5. 出结果后**先看这一行**：报告里的 **光轴夹角**。
   - 这是判断"你的装置到底是不是 90°"的**唯一证据**（由标定 R 算出，不是手填的）。
   - 若你按 90° 摆的，这里却是 30°，说明**摆位或共同区不对**，先别录数据。

**命令行等价**（不想点界面时用）：

```bat
python apps\calibrate_stereo.py --stereo-mode angled --skip-fov ^
  --cols 8 --rows 5 --square 25 --target 40 ^
  --save-pairs outputs\pairs90 --report-png outputs\calib90.png
```

```bat

```

现场必须做到：

- [ ] 球在**两路共同可见区**里缓慢移动，别出画。
- [ ] 别开/关房间灯（亮度突变会干扰闪光检测）。
