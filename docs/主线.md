# 工作主线（唯一入口）

> **这份文档回答一个问题：现在做到哪一步了，下一步该做什么。**
> 与其它文档冲突时：**状态以本文为准**，规则以 `AGENTS.md` 为准。
> 本文只写"一条主线"，散落的工具/实验/未接线的模块放在 §5「孤岛清单」。

---

## 0. 一句话

> 目标：两台普通 USB 相机 → 球的**三维轨迹**（米制）→ 未来位置预测 → 可视化/控制。
> 当前卡点：**标定质量**（这一步不过，后面全是错数）。

---

## 1. 主线六段（每段只认一个入口）

| # | 阶段 | 唯一入口 | 输入 → 输出 | 状态 |
|---|------|----------|-------------|------|
| 1 | **标定** | `启动程序.bat calibrate` / GUI 第 1 步 | 棋盘图 → `config/stereo_calibration.{json,npz}` | ✅ 可用（当前：parallel，基线 124.0 mm，夹角 1.38°） |
| 2 | **采集** | GUI 第 1 步录制 / `启动程序.bat run` | 相机 → `data/sessions/<时间戳>/` | ✅ 可用（含闪光同步） |
| 3 | **三维重建** | `apps/run_stereo_video.py` | 会话目录 → `derived/traj3d.csv` + `traj3d.json` | ✅ 可用（交会残差见日志） |
| 4 | **轨迹后处理** | 同上（内置） | 原始 → S-G 平滑 / 3D Kalman | ✅ 可用 |
| 5 | **预测** | 同上（2D 已有；3D 见 §5） | 当前状态 → 0.1–0.5 s 位置 | ⚠️ 2D 已接；**3D 未接** |
| 6 | **输出 / 可视化** | `apps/export_visualization.py` 或 GUI | `visualization.json` → 3D 查看器、`annotated.mp4` | ✅ 可用（世界系可选） |

**一条命令跑完 3→6**：`python apps/run_all.py --session data/sessions/<时间戳>`
（缺什么会跳过并说明原因；退出码 3 = 有跳过，不是"全好"）

## 2. 坐标契约（唯一规定，其它地方不许自创）

```
相机内参去畸变后          → 各自原始像素系
三角化输出                → left_camera（米制，X 右 / Y 下 / Z 前）
导出可视化（可选）         → world（若 config/world_frame.json 存在）
```

- **内部计算一律 `left_camera`**；只在**导出那一刻**转 `world`。
- `rectified_left_camera` 是 `parallel` 模式的历史产物，**只对当前这份 parallel 标定有效**；
  新标定一律走 `angled`（零共视情况用 `--method chain`），不要再新增 `rectified_*` 消费者。
- 没有 `world_frame.json` 时，导出必须写 `coordinate_system="left_camera"` 并说明"未设置世界系"。
  **不许静默当世界系。**

---

## 3. 现在做什么（按顺序，一次只做一件）

1. **重标定**（最高优先）：GUI 第 1 步 →「单板链式标定」三段拍图 → 开始标定。
   判据：`实测光轴夹角` 与物理夹角一致、`T_AB 重复性` 在 0.5°/2 mm 内。
2. **复检**：`启动程序.bat verify`，看匹配率与交会残差；不达标不进入下一步。
3. **跑一次真实三维**：录一段有明确运动的会话 → `run_all.py` → 看 `traj3d.csv` 的量级是否合理
   （球在 1 m 处、直径 40 mm，Z 应该在这个量级）。
4. 标定稳了再谈预测/多球——**在错的坐标上做预测，只会得到更精致的错**。

---

## 4. 判定"这轮做完了"的标准

| 阶段 | 通过判据 |
|------|----------|
| 标定 | 复检匹配率 ≥ 80%，交会残差中位数 ≤ 10 mm |
| 三维 | 静态标定板上的已知点，重建误差 ≤ 10 mm @ 1 m |
| 轨迹 | 平滑前后不改变量级（S-G 只去噪不改趋势） |
| 预测 | 0.3 s 预测误差 ≤ 30 mm（需已知轨迹真值） |

> 以上都是**可证伪**判据。达不到就写"未达标 + 实测值"，不要用形容词。

## 6. 明确不做的（避免虚假进度）

- **实时双路**：需要先有稳定标定与带宽实测，现做只会得到卡顿的错数。
- **1 m 处 ≤10 mm 的独立三维真值**：需要外部测量设备（卷尺不够）。
- **极线压到 0.3 px**：受镜头与板面平整度限制，先把标定方法做对再说。
- **YOLO/SAM、Unity**：与环境/算力绑定，不是主线。
