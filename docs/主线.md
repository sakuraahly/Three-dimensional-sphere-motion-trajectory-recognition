## 2. 坐标契约（唯一规定，其它地方不许自创）

```
相机内参去畸变后          → 各自原始像素系
三角化输出                → left_camera（米制，X 右 / Y 下 / Z 前）
导出可视化（可选）         → world（若 config/world_frame.json 存在）
```

- **内部计算一律 `left_camera`**；只在**导出那一刻**转 `world`。
- `rectified_left_camera` 是 `parallel` 模式的历史产物，**只对当前这份 parallel 标定有效**；
  新标定一律走 `angled`（零共视情况用 `--method chain`），不要再新增 `rectified_*` 消费者。
- 没有 `world_frame.json` 时，导出必须写 `coordinate_system="left_camera"` 并说明"未设置世界系"。
  **不许静默当世界系。**

## 4. 判定"这轮做完了"的标准

| 阶段 | 通过判据 |
|------|----------|
| 标定 | 复检匹配率 ≥ 80%，交会残差中位数 ≤ 10 mm |
| 标定·跨路一致性 | 报告「跨路一致性」中位 ≤ 2 mm、旋转中位 ≤ 0.5°（`n ≥ 2` 才算；`n<2` 报告写"数据不足"，**不能当合格**） |
| 标定·泛化 | 4 折交叉验证**右目** `ratio`（测试/训练 RMS 中位）≤ 1.5，且 `leak_check="ok"`（没报 `used_train_idx` 的结果一律算"未验证"）。⚠️ 1.5 / 2.5 两个门限**无推导、是经验值**；比值随口径与样本变化，**只作筛查信号，不作验收依据**（两目合并与左目只用于看被稀释了多少） |
| 标定·不确定度 | 报告「外参不确定度」的 `σ_B` ≤ 基线的 0.5%（报告值，不是硬门限）。⚠️ `σ_Z` 实测**偏低**，**只当下限、不当安全余量**；旧 `depth_sigma_mm` 不含 `σ_B`，别拿它验这一条 |
| 三维 | 静态标定板上的已知点，重建误差 ≤ 10 mm @ 1 m |
| 轨迹 | 平滑前后不改变量级（S-G 只去噪不改趋势） |
| 预测 | 0.3 s 预测误差 ≤ 30 mm（需已知轨迹真值） |

> 以上都是**可证伪**判据。达不到就写"未达标 + 实测值"，不要用形容词。

## 6. 明确不做的（避免虚假进度）

- **实时双路**：需要先有稳定标定与带宽实测，现做只会得到卡顿的错数。
- **1 m 处 ≤10 mm 的独立三维真值**：需要外部测量设备（卷尺不够）。
- **极线压到 0.3 px**：受镜头与板面平整度限制，先把标定方法做对再说。
- **YOLO/SAM、Unity**：与环境/算力绑定，不是主线。
