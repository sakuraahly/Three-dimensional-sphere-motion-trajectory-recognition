## 2. 已定位的根因（带证据）

### 2.1 假红

- 现象：`[不达标] 角色名 + --backend dshow -> **拒绝**`，退出码 1。
- 实际异常文案：`没有为「left」选定相机，已中止`，不含判据要的 `不能一起用` + `PnP`。
- 机制：`from_args` 先在 `stereo/pair_source.py:614-615` 解析角色；
  角色解析失败就抛，**后端守卫在 `:705` 之后，根本没被走到**。
- 触发条件：`config/cameras.json` 绑的是两台 aoni，本机当前只枚举到内置相机。
- 判据缺陷：`tests/selftest_pair_source.py:429` 只认一种文案，
  没有把"角色解析"这一步替换成可控输入 —— 正是项目记过的坑 24
  （"替身测试必须断言替身真的走到了那一步"）的同型问题。

> **产品行为不变**：无相机时 `from_args` 仍会先报"没有为「left」选定相机"；
> 本测试只让**判据**不再依赖这个环境状态，**不改报错顺序**。

**反向自证 A：旧判据为什么是假红**（去掉替身，直接用真实角色解析）—— 命令与实测输出：

```powershell
& $PY -c @"
import argparse, sys
from pathlib import Path
sys.path.insert(0, str(Path('.').resolve()))
from stereo import from_args
ns = argparse.Namespace(left='left', right='right', left_video=None, right_video=None,
                        left_dir=None, right_dir=None, width=1920, height=1080, fps=60,
                        backup_camera=None, backend='dshow', auto_cameras=False)
try:
    from_args(ns)
except RuntimeError as e:
    msg = str(e)
    print('FIRST LINE:', msg.splitlines()[0])
    print('contains 不能一起用 =', '不能一起用' in msg, '| contains PnP =', 'PnP' in msg)
"@
```

实测输出（退出码 0：脚本自己捕获了异常）：

```
FIRST LINE: 没有为「left」选定相机，已中止。
contains 不能一起用 = False | contains PnP = False
```

即旧判据在当前无相机环境**必然为假**。修后能绿，是因为替身把「角色解析」换成
可控输入，而**守卫本身仍走产品代码**。

**反向自证 B：新判据不是空转**（绕过守卫：把 `INDEX_BACKEND` 临时改成 DSHOW，
使 `api != INDEX_BACKEND` 不成立）：

```powershell
& $PY -c @"
import importlib.util, pathlib, sys, tempfile
sys.path.insert(0, '.')
import cv2
import sphere_tracker.sources as s
s.INDEX_BACKEND = cv2.CAP_DSHOW          # 让守卫条件 api != INDEX_BACKEND 不成立
spec = importlib.util.spec_from_file_location('tps', 'tests/selftest_pair_source.py')
mod = importlib.util.module_from_spec(spec)
spec.loader.exec_module(mod)
with tempfile.TemporaryDirectory() as d:
    ok = mod.test_from_args(pathlib.Path(d))
print('test_from_args ->', ok)
assert not ok, '守卫被绕过时测试必须变红'
print('反向自证通过：守卫被绕过后，新判据确实变红')
"@
```

实测输出（退出码 0：`assert not ok` 成立）：

```
  守卫没有拒绝：from_args 成功返回了（已用桩，没有真开相机）
  [不达标] 角色名 + --backend dshow -> **拒绝**（否则静默用错相机）
  [通过] 替身确实被调用：left/right 各一次
  [不达标] 守卫在构造 PairSource 之前就拒绝（没真开相机）
test_from_args -> False
反向自证通过：守卫被绕过后，新判据确实变红
```

两条"非空转"判据分工不同，**不要混用**：

| 判据 | 守什么 | 守卫被绕过时会怎样 |
| ---- | ------ | ------------------ |
| `Counter(resolved) == {"left": 1, "right": 1}` | 解析没被绕过 | **仍然通过**（解析确实发生了） |
| `built == []` | 守卫在构造 `PairSource` 前拒绝 | **变红** |
| 文案含"不能一起用" + "PnP" | 守卫按契约拒绝 | **变红** |
