# 2026-10-20 · 金属球双目数据验收（下一步执行单）

> **目标**：先用 2~3 条新录制证明"金属球 + GUI 点选 + 双目三维 + 标准数据"
> 在真机上可重复，再决定要不要做 Kalman/预测。
> **本阶段不做预测**（用户明确要求）；不改检测器/标定，先收数据。
>
> 基线：`20261019-221550` 已达 **293/301 = 97.3%** 左右匹配，
> Z 0.235–0.348 m。现在需要**第二条、第三条**来证明不是偶然。

## 1. 录制前的固定条件

| 项 | 要求 |
| --- | --- |
| 灯光 | 正常开灯，画面平均亮度 > 60；不要黑房间 |
| 相机 | 两台 aoni，MSMF，1920×1080@30；固定不动 |
| 球 | 同一颗金属球；**全程在左右两路画面内** |
| 背景 | 球后方不要放会反光的圆形物/白袋；减少干扰 |
| 闪光 | 开始后立刻闪一次，结束前再闪一次 |
| 时长 | 10 秒（301 帧左右） |
| 摆动 | 中等幅度，不要甩出画面；手不要长时间挡住球 |

> 录制时看 HUD：`FLASH NOW!` 出现后闪；结束前 `FLASH AGAIN BEFORE END` 再闪。
> 录完先看终端 `[同步诊断]`：最大亮度跳变应 ≥2.0，`method=flash`。

## 2. 需要录的会话

### A. 重复性会话（必做）

同一摆长、同一相机位置，按上面的条件录 **10 秒**。
目的：验证 221550 的 97.3% 不是偶然。

### B. 第二次重复（必做）

隔几分钟再录一条同样的 10 秒（球/相机不要动）。
目的：验证 seed/同步/检测的可重复性。

### C. 变条件会话（可选，A/B 都通过再做）

改变摆幅（更大或更小）或球的起始位置，仍保持全程可见。
目的：验证检测器不只对某一条轨迹有效。

> 如果 A 或 B 出现球出画面/被挡/同步失败，**直接重录**，不要用坏数据调参。

---

## 3. 每条会话的执行步骤

### 3.1 录制

1. 打开 `启动程序.bat`；
2. 第 2 步检测方法选 `specular`；
3. 第 3 步点「录制双目（无损）」，录 10 秒；
4. 按 HUD 提示闪光；
5. 记下会话目录 `data/sessions/<id>`。

### 3.2 录制校验（必须 0 warning）

```powershell
python apps\tools\check_dataset.py data\sessions\<id> --strict
```

通过标准：

```text
错误 0，警告 0
同步：flash +N 帧
左右帧数差 ≤1
平均亮度 > 60
```

不通过就重录，不要进入下一步。

### 3.3 点选 seed

1. 第 3 步点「点选球（双目 seed）」；
2. 选会话目录；
3. 左图点球心，右图点球心；
4. 滚轮把圆圈调到球的外轮廓；
5. 保存 `derived/seeds.json`。

### 3.4 跑离线双目

第 3 步点「离线双目（会话）」，选同一个会话。
（GUI 会自动带 `--seed-json`；没有 seed 时会先弹点选窗口。）

期望输出：

```text
匹配 ≥ 90%
无左=0，无右=0
极线拒 ≤ 10%
交会残差中位 ≤ 2 px，最大 ≤ 5 px
```

### 3.5 看三维

```powershell
python apps\view_3d.py data\sessions\<id>
```

检查：

- 轨迹连续，没有“瞬移”；
- 没有长时间停在一个点；
- `Z` 量级合理（本装置约 0.2–0.5 m；不应出现 1 m 以上突变）；
- 播放一遍，球点沿轨迹移动。

### 3.6 记录结果

把下面一行填进本文件的“结果表”，或直接把日志数字发回来：

```text
会话 id | 帧数 | sync | 匹配/总数 | 无左/无右/极线拒 | Z 范围 | 残差中位/最大 | 备注
```

## 4. 验收标准

| 指标 | 通过线 | 不通过怎么办 |
| --- | --- | --- |
| `check_dataset --strict` | 0 error / 0 warning | 重录（球出画面/同步失败/黑视频） |
| 左右匹配率 | ≥ 90% | 先检查 seed 是否点在球上；再检查球是否全程可见 |
| 无左 / 无右 | 都为 0 | 看对应视频，球是否被手/框挡住 |
| 极线拒 | ≤ 10% | 检查左右 seed 是否同一帧、角色是否装反 |
| 交会残差中位 | ≤ 2 px | 检查标定/球心是否偏 |
| 三维连续性 | 无 >20 cm/帧瞬移 | 检查误配/标定；不要用 Kalman 掩盖 |
| `traj3d.json` / `visualization.json` | 存在，`n_matched` 与 CSV 一致 | 重跑 `export_visualization.py` |

**A、B 两条都达到 ≥90%，才算“可重复”。**
只达到一条 → 重录，不调算法。
