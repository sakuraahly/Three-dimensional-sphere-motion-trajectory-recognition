# 会话清理与回收站（2026-10-21）

## 1. 一句话

管理面板新增“清理”与“回收站”：先预览、只移到 `_trash`，恢复免费；
彻底删除只发生在回收站，并要求输入 `DELETE` 二次确认。

## 2. 为什么谨慎

`data/sessions` 里是**不可再生的原始视频**。直接 `rmtree` 一次误点就没了，
所以第一阶段**不提供“直接永久删除会话”**。

安全规则：

- 只允许 sessions 根目录的**直接子目录**，或其 `derived/`；
- 拒绝符号链接、`..` 逃逸、根目录本身、`_trash`；
- 先显示“将移动哪些路径、多少文件/字节”的预览；
- 移动目标固定为 `sessions 父目录/_trash/<时间>_<label>/`；
- 恢复免费；彻底删除必须选回收站批次 + 输入 `DELETE`；
- 原始视频只有选择“整个会话”才会被移动。

## 3. 功能

### 清理

- 整个会话（含 `left.mkv` / `right.mkv`）
- 只清 `derived/`（保留原始视频和 `session.json`）
- 保留最新 N 个
- 先预览再移到回收站

入口：

- 双目工作台：`清理…`
- 数据管理：`清理…`（支持多选）

### 回收站

- 列出批次、时间、方式、项数、大小；
- 恢复选中（恢复到原相对路径；目标已存在则拒绝）；
- 彻底删除选中（输入 `DELETE`）。

## 4. 包结构

```text
sessions/                 原始会话（不动）
_trash/                   回收站（与 sessions 同级）
  20261021-193000_manual/
    manifest.json
    sessions/<原相对路径>
```

## 5. 验收

```powershell
python -m py_compile apps/_cleanup.py apps/cleanup_dialog.py apps/data_manager.py
python tests/selftest_launcher_params.py
```

- 只清 derived 不动原始视频；
- 软删除后可恢复，恢复后批次清空；
- 保留最新 N 个生效；
- sessions 根目录之外/符号链接被拒绝；
- 彻底删除只作用于回收站批次。

## 6. 明确不做

- 不做“选中会话直接永久删除”按钮；
- 不自动清理、不按时间自动删；
- 不清理 `outputs/`、日志、导出包（以后单独做）。
