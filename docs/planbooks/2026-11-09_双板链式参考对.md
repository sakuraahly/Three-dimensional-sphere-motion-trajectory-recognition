# 计划书：双板链式标定补「参考对」（方案 A）

日期：2026-11-09
触发：用户问「分开拍摄、又不识别另一块板，为什么前面不能用单板」，追查后发现
**当前双板 GUI 流程在数学上缺一步**，用户选择方案 A，并要求「GUI 必须最小白、最直接」。

---

## 1. 要解决的问题（先给证据）

链：

```
T_{C_R←C_L} = T_camR_B · T_AB · inv(T_camL_A)
```

`T_AB`（A↔B 刚性相对位姿）确实与支架整体摆放无关，**但链上两端的位姿必须来自
同一个支架摆放**。设两次拍摄时支架摆放为 `G_X`、`G_Y`：

```
链 = inv(C_R) · G_Y · inv(G_X) · C_L      真值 = inv(C_R) · C_L
```

只有 `G_X = G_Y` 才相等。合成真值实测（90° 装置、垂直刚性双板、`T_AB` 常量）：

| 两端位姿 | 旋转误差 | 平移误差 |
|---|---:|---:|
| 同一摆放 | 0.0000° | 0.000 mm |
| 差 10° / 2 cm | **10.0000°** | **28.284 mm** |
| 差 30° / 5 cm | **30.0000°** | **70.711 mm** |

现有代码 `apps/calibrate_stereo.py` 在双板模式下取
`argmin(mono_l["per_view"])` 与 `argmin(mono_r["per_view"])` 两帧 —— 两段各自
「板可移动、五区覆盖」，几乎必然是不同摆放。而双板模式 `cross_poses = None`，
`--baseline-mm` GUI 从不传，**没有任何东西会报警**：会静默给出错外参。

`docs/交接文档.md` §67.1 那句「任意两组板位姿都能组合」是错的，须更正。

现有合成判据 `test_chain_extrinsics_90deg` 没暴露这个问题：`T_cr_B_i` 是从**同一帧 i**
的 `T_cl_A_i` 推出来的，链用 `[0]/[0]`，天然同摆放，从没测过 `i≠j`。

---

## 2. 方案 A（用户已选定）

双板模式加一步 **「参考对」**：

> 把组合装置（A、B 两板刚性固连的支架）**摆好别动**，左右相机**同时各拍一张**
> （左看 A、右看 B）。程序一次点按自动完成两路采集，同名文件天然成对。

- 内参段的移动多姿态图 **只用来求 K1/D1、K2/D2**；
- 链两端位姿 `T_camL_A` / `T_camR_B` **改从参考对取**（用内参段求出的 K/D 做 PnP）；
- `T_AB` 仍由同框图（`pair`）求，它与摆放无关，不要求与参考对同一次拍摄；
- **双板模式缺参考对 → 拒绝出数**，不再静默算错。

单板模式（`--same-board`）本来就有 `--ref-left/--ref-right` 参考段，不受影响。

### 为什么不是别的方案

| 方案 | 为何不选 |
|---|---|
| B 配对序列（每个姿态左右同时拍） | 要把采集改成同步双路 + 配对清单，改动面大，用户要多理解一个概念 |
| C 只用多组 (i,j) 散布做事后拦截 | 最便宜但只拦截、救不了已拍数据；用户要的是能一次拍对 |
| 删掉中央区域 / 降覆盖门限 | 上一轮已证实是误读，撤销了，**与本问题无关** |

## 3. GUI 呈现：4 步，每步一句人话，不出现任何术语

| 步 | 按钮上看到的话 | 背后发生什么 |
|---|---|---|
| ① | 拍 A 板：只用左相机，把 A 板在画面里摆出各种角度 | 单路多姿态，求 K1/D1 |
| ② | 拍 B 板：只用右相机，同样摆出各种角度 | 单路多姿态，求 K2/D2 |
| ③ | **组合装置摆好别动**，两路同时各拍一张 | `--both --target 1 --auto`，一次点按自动存一对 |
| ④ | 让一台相机同时看到两块板，拍 5 张 | `--pair` 同框图，求 T_AB |

- 步骤数 3 → 4，但**每步都是「摆好、点一下」**，不需要用户理解
  `T_AB` / 姿态簇 / 摆放前提。
- 方法下拉的说明改成白话四句，并写清「第 ③ 步不能省」的一句话理由。
- 拍完、自检、标定三个按钮的位置与名称一个都不改。

## 6. 已知边界（写清楚，不装懂）

- 程序**无法验证** A/B 是否真的刚性固连。参考对只保证「两端同一摆放」，
  刚性仍是靠人守的物理约定；用两块独立板会静默给错数。
- 参考对只拍 1 对，无法评估重复性；自检会提示「可多拍 1~2 对更稳」，
  但不强制。
- 老数据（没有参考对目录）会被**明确拒绝**而不是照旧出数 —— 这是刻意的
  破坏性变更，用户已同意方案 A。
- 参考对要求两路各自**完整**检出整块板；大角度装置下若一路只能看到边缘，
  这一步拍不出来，需调整支架摆放。
