# 数据管理面板 · 脱敏批量导出（2026-10-20）

## 1. 一句话

在主界面右上角打开独立的「数据管理」面板：勾选会话 → 选类别 → 自动脱敏 →
打成带 `sessions/<id>/...` 目录结构的 zip。

## 2. 选择方式

- 单行 checkbox：点第一列；
- 全选 / 全不选 / 反选；
- **选到此处**：先点起点，再点终点，Shift+点行也可；
- **按时间选择**：填 `YYYY-MM-DD` 或 `YYYY-MM-DD HH:MM:SS`；
- 时间选择会替换当前勾选；其余按钮在现有勾选上增删。

## 3. 导出类别（默认不含视频）

| 类别 | 默认 | 内容 |
| --- | --- | --- |
| metadata | ✅ | 脱敏 `session.json` + `left/right_times.csv` |
| derived | ✅ | `seeds.json` / `traj3d.json` / `visualization.json` / CSV |
| plots | ✅ | `traj3d.png` / `sync_brightness.png` |
| calibration | ✅ | 该会话的标定 JSON/NPZ |
| annotated | ❌ | `annotated.mp4`（有画面） |
| raw | ❌ | `left.mkv` / `right.mkv`（很大、有画面） |

视频不做自动打码；选了会先弹隐私确认。

## 4. 脱敏规则

- 删除左右相机 `identity` / `name` / `port`；
- 删除会话 `label` / `notes`；
- 删除 `environment.platform`；
- 保留 `created`、帧数、标定参数、轨迹数值，便于复现；
- 不复制绝对路径；manifest 里只有包内相对路径。

## 5. 包结构

```text
<zip根>/
  README.md
  manifest.json
  sessions/<会话ID>/
    metadata/session.json
    metadata/left_times.csv
    metadata/right_times.csv
    derived/...
    derived/plots/...
    calibration/...
    videos/annotated.mp4        # 可选
    videos/raw/...              # 可选
```

## 6. 验收

```powershell
python -m py_compile apps/data_manager.py apps/_data_export.py
python tests/selftest_launcher_params.py
```

- 脱敏字段确实消失；
- 默认包不含视频；
- zip 有 README/manifest 和按会话分类的目录；
- 选择/时间/区间勾选不崩；
- 选中会话可 **『查看 3D + 视频』**（双击也行）；换 `数据目录…` 可看任意根目录；
- 没有 `annotated.mp4` 时询问后只开 3D。

## 7. 明确不做

- 不做视频自动打码/模糊；
- 不做云端上传；
- 不修改原始 `data/sessions`；
- 不把导出包写入 `data/`（输出默认 `outputs/exports/`）。
