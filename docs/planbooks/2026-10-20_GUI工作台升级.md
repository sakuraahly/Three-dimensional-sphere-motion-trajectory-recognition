# 2026-10-20 · GUI 双目工作台升级（计划）

> 目标：把现在散在终端/多个按钮里的操作，收成**一个会话工作台**：
> 录制 → 校验 → 点选 seed → 跑双目 → 看 3D → 导出标准数据。
> **本阶段不做预测、不做实时双目、不做自动 seed**（点选是刻意保留的人工确认）。

---

## 1. 现在的问题

| 现状 | 用户要记/要做的事 |
| --- | --- |
| 录制、离线双目、点选 seed 是三个独立按钮 | 先录、再找目录、再点选、再回来跑 |
| `check_dataset` 只在终端 | 录完不知道同步/黑帧/帧数是否合格 |
| 3D 查看器只能命令行 | 跑完还要切终端 `python apps/view_3d.py ...` |
| 标准 JSON 已自动生成，但 GUI 不展示 | 不知道 `traj3d.json` / `visualization.json` 在哪、是否成功 |
| 任务日志/状态分散 | 失败后要自己判断下一步 |

**不是功能缺失，是操作路径没闭环。**

---

## 2. 目标界面（第 3 步“双目工作台”）

```text
┌ 双目工作台 ─────────────────────────────────────────────┐
│ 最近会话  [下拉/列表：20261020-095331  flash ✓ seed ✓]   │
│                                                         │
│ ① 录制 10 秒   [录制双目]                                │
│ ② 数据校验     [校验]   帧数 302/303  sync flash +1 ✓    │
│ ③ 点选球心     [点选 seed]  左(894,732,58) 右(561,747,58)│
│ ④ 跑双目       [离线双目]  匹配 97.7%  残差 1.95 px     │
│ ⑤ 看三维       [打开 3D 查看器] / [内嵌预览]             │
│ ⑥ 标准数据     [导出 JSON] traj3d.json / visualization.json│
│                                                         │
│ 状态：20261020-095331 已通过；B 095403 帧数不一致，需重录 │
└─────────────────────────────────────────────────────────┘
```

关键原则：

- **每一步只显示“当前能不能做 + 做完结果 + 下一步”**，不让用户猜；
- 录制完成后自动选中新会话；
- 校验失败直接给原因与“重录”，不进入点选；
- seed 仍由人点（金属球/高光靠猜不可靠）；
- 3D 先做“打开独立查看器”，稳定后再考虑内嵌 matplotlib 画布；
- 所有操作走现有脚本 + 任务管理器，不把算法搬进 GUI。

## 4. 验收标准

| 场景 | 通过标准 |
| --- | --- |
| 录制完成 | 自动校验；0 warning 才亮“点选” |
| 坏会话 B（302/304） | 状态卡明确“帧数不一致，重录”，不劝进三维 |
| 点选 seed | 保存后 `seeds.json` 状态变为 ✓ |
| 跑双目 | 完成后显示匹配率/残差/Z 范围，不需看终端 |
| 看 3D | 按钮能打开 `view_3d.py`，进程可被任务管理器收掉 |
| 导出 | `traj3d.json` / `visualization.json` 存在且可打开 |
| 无终端 | 从录制到看 3D 全在 GUI 完成（seed 点选除外） |
| 回归 | fast 20/20；23 个测试数不变 |

---

## 5. 明确不做

- 不做预测/Kalman 开关（用户明确先不做）；
- 不做实时双目（`run_realtime.py` 仍单目）；
- 不做自动 seed/自动 Hough 初始化（金属球不可靠）；
- 不把 `check_dataset`/`run_stereo_video` 的逻辑复制进 GUI；
- 不改测试数量；不新增根目录启动脚本。

---

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| `启动程序.py` 继续变大 | 事实/状态放 `apps/_workbench.py`，GUI 只做展示与命令 |
| 校验/离线是长任务，卡 UI | 全部走现有任务管理器，按钮按任务状态禁用 |
| 用户不知道“为什么不能点” | 每个禁用按钮旁显示 `problems[0]` |
| 3D 内嵌复杂 | 第一版只打开独立查看器 |
| 状态过期 | 每次操作后重扫会话目录，不缓存 |
