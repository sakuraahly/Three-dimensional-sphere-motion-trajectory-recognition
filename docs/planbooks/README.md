# 计划书索引

> **这个目录只放"计划书"** —— 一次性的、有明确起止的工作计划。
> 长期目标与里程碑不在这里（那在 `../计划书.md`）。

---

## 命名约定

```
docs/planbooks/<YYYY-MM-DD>_<主题>.md
```

- 日期是**计划写下的那天**，不是完成日 —— 便于按时间排序看演进。
- 主题用中文、短、能看懂即可。
- 一份计划书**做完后不删**：它是"当时为什么这么排优先级"的记录，比结论更值钱。

## 与相邻文档的分工（别写重）

| 文档 | 管什么 | 什么时候看 |
| ---- | ------ | ---------- |
| `../计划书.md` | **长期**目标、M0–M8 里程碑、风险清单 | 想知道整个项目还剩什么 |
| `../交接文档.md` | **现状**：什么能用、什么没做、踩过什么坑 | 动手之前 |
| **`planbooks/*.md`（这里）** | **一次具体工作**的范围、优先级、验收、明确不做 | 要开工时 |
| `../决策记录.md`（若建） | 为什么这么定、否掉了什么 | 想推翻某个决定时 |

> **一份计划书里必须有的四件事**：要解决什么 / 怎么算做完了 / **明确不做什么** / 做完怎么验证。
> 少了第三件，范围一定会膨胀；少了第四件，做完也不知道算不算完。
