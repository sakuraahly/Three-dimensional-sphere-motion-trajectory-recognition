## 3. 决策

1. **默认仍 1080p**：在真机 `doctor` 证明 1440p/4K 两路稳定前，不把 4K 设为默认。
2. **动态而不是到处写死**：分辨率档只能有一个来源；GUI/录制/标定/检测/doctor 读取同一份 profile；支持能力由探测决定，不支持明确回退。
3. **分辨率绑定校验**：标定、录制、离线分析的分辨率必须一致；不一致报错，不静默缩放。
4. **实时入口必须传分辨率**：当前固定 720p 的行为要改为从 profile/用户选择传入。
5. **不改旧 1080p 行为**：旧会话、旧标定、旧命令仍按 1080p 路径工作。
